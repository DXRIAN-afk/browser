Browser

Ein schlanker Browser mit der gleichen Engine wie Microsoft Edge und Google Chrome. Alle Websites, die dort laufen, laufen auch hier.

Herunterladen
  1. ZIP-Datei herunterladen und entpacken (Rechtsklick → Alle extrahieren).
  2. Im entpackten Ordner Browser.exe starten.
  3. Falls Windows „Der Computer wurde durch Windows geschützt“ anzeigt: auf Weitere Informationen und dann Trotzdem ausführen klicken. Das kommt, weil das Programm nicht kostenpflichtig signiert ist.

Online ausprobieren

Ohne Installation direkt hier im Browser. Die Seiten werden über diesen Server geladen, darum funktionieren einfache Seiten gut, große Seiten wie Google, YouTube oder Seiten mit Login aber oft nicht.
